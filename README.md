# Resume Screening & Candidate Ranking System

## Overview

This project is a Machine Learning and NLP-based Resume Screening System developed as part of Future Interns Machine Learning Task 3.

The system automatically analyzes resumes, compares them against a job description, calculates similarity scores, and ranks candidates based on their suitability for the role.



## Features

* Resume text processing
* Job description matching
* Candidate similarity scoring
* Ranking of applicants
* Visualization of top candidates
* NLP-based resume screening



## Technologies Used

* Python
* Pandas
* Scikit-learn
* TF-IDF Vectorization
* Cosine Similarity
* Matplotlib



## Dataset

This project uses the Resume Dataset available on Kaggle:

https://www.kaggle.com/datasets/snehaanbhawal/resume-dataset

The dataset is not included in this repository due to its large size. Download the dataset and place Resume.csv inside the datasets folder before running the project.



## Workflow

1. Load resume dataset
2. Clean and preprocess resume text
3. Convert text into TF-IDF vectors
4. Compare resumes with job description
5. Calculate similarity scores
6. Rank candidates
7. Visualize top-ranked candidates

   

## Results

The system successfully ranked candidates based on relevance to the provided job description and generated a visualization of the top candidate match scores.
